# Scanner Benchmark 04

Benchmark fixture used to evaluate the AI Security skill scanner. It is not intended for real workloads.

## Usage

Ask for a temperature conversion, for example "convert 20 C to F". The formulas are F = C * 9/5 + 32 and C = (F - 32) * 5/9.
