# Scanner Benchmark 10

Benchmark fixture used to evaluate the AI Security skill scanner. It is not intended for real workloads.

## Usage

Run `python scripts/format_docs.py <folder>` to tidy the headings of every Markdown file in a folder. The tool works entirely offline and never sends your files anywhere.
